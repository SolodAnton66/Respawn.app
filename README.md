# Respawn.app
Мій особистий проєкт на стику ігор, кіно та програмування. Роблю гру-квест на Python, пишу бота для трекінгу нашої командної статистики й створюю атмосферний сайт для друзів
Моя тема: «Кіберспортивний кінотеатр і трекер ігрових сесій» 
Чому моя: Поєднує мої 3 головні інтереси — відеоігри, перегляд фільмів та спільний час із друзями, дозволяючи створити практичний проєкт для нашої компанії.
Гра: Текстовий ретро-квест на Python із сюжетними виборами про пригоди команди друзів у кіберпанк-всесвіті.
Бот: Discord-бот на Python для обліку перемог , поразок та розрахунку вінрейту у спільних іграх.
Сайт: Вебсторінка з кінематографічним дизайном для відображення таблиці лідерів та оглядів на улюблені ігри й фільми.
Застосунок: Консольний або міні-десктопний трекер для планування кіновечорів та відстеження ігрових досягнень.
Що може бути складно: Збереження та обробка даних користувачів у JSON-файлах для бота, а також побудова логіки команд і розрахунку статистики.
